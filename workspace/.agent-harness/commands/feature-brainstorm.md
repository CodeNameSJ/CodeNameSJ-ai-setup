Start a collaborative feature design session before implementation planning.

Use the brainstorm agent to:
1. Read the PRD (or requirements.md if no PRD yet) from the feature folder
2. Ask clarifying questions one at a time to understand intent, constraints, and success criteria
3. Propose 2-3 approaches with product + technical trade-offs
4. Present the chosen design in sections, getting approval at each step
5. Write the approved design to ai-specs/<feature-name>/design-{topic}.md

HARD GATE: No implementation planning until the user approves the design.
