# CodeNameSJ-ai-setup

Machine-level AI agent configuration, shared by Claude Code, Cursor, and Codex.
Companion to `CodeNameSJ-dotfiles`, which covers shell and terminal config.

## Layout

| Path | Lives at | Contents |
|---|---|---|
| `workspace/` | `/Users/shubh/Workspace/` | `AGENTS.md`, `CLAUDE.md`, `.agent-harness/` — the workspace contract and the provider-neutral harness |
| `user/` | `/Users/shubh/` | `.agent-harness/` (audit, update, backups tooling) and `.agents/skills/` (personal cross-workspace skills) |

The real paths are symlinks into this repo:

```
/Users/shubh/Workspace/AGENTS.md       -> CodeNameSJ-ai-setup/workspace/AGENTS.md
/Users/shubh/Workspace/CLAUDE.md       -> CodeNameSJ-ai-setup/workspace/CLAUDE.md
/Users/shubh/Workspace/.agent-harness  -> CodeNameSJ-ai-setup/workspace/.agent-harness
/Users/shubh/.agent-harness           -> /Users/shubh/Workspace/CodeNameSJ-ai-setup/user/.agent-harness
/Users/shubh/.agents                  -> /Users/shubh/Workspace/CodeNameSJ-ai-setup/user/.agents
```

Provider adapter directories (`.claude/`, `.cursor/`, `.codex/`, `.agents/` under the
workspace root) are **not** in this repo. They are thin symlinks regenerated by
`python3 .agent-harness/sync.py`; restore steps are in
`workspace/.agent-harness/docs/SETUP.md`.

## Not tracked here

- `workspace/.agent-harness/mcp/servers.json` — inherits credentials from native provider
  configs. Back it up through a secret store, never this repo.
- `workspace/.agent-harness/generated/` — rebuilt from `agents/`, `commands/`, and
  `provider-agent-metadata.json` by `sync.py`.
- Operational backups and temporary state live outside the repo in
  `~/.local/share/agent-harness/{backups,tmp}/`; neither belongs in Git.

## Restore on a new machine

```bash
git clone git@github.com:CodeNameSJ/CodeNameSJ-ai-setup.git ~/Workspace/CodeNameSJ-ai-setup
cd ~/Workspace/CodeNameSJ-ai-setup
./bootstrap.sh --dry-run   # review
./bootstrap.sh
```

`bootstrap.sh` creates every symlink, refuses to overwrite real files, and is safe to
re-run. It then prints what it cannot do for you: cloning `ai-frontend` as a sibling
(the skill links point into it) and recreating `mcp/servers.json` from your secret
store. Finish with the `sync.py` / `audit.py` steps it lists.

Home-level links use the clone's absolute path, so the clone need not be directly
under `~/Workspace`. `--dry-run` does not create directories or links.
Feature workflows use `/feature-brainstorm` and `/feature-docs` to avoid collisions
with personal skills. The permission hook approves file edits only inside the
resolved workspace (or Claude scratch directories); Bash uses native permissions.

Full detail: `workspace/.agent-harness/docs/SETUP.md` and `user/.agent-harness/README.md`.
